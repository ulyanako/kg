### Лабораторные работы по компьютерной графике (Семестр 5)

Репозиторий содержит отчеты, исходный код и готовые автономные сборки приложений для Windows. 

### Структура проекта

* lab1/ — Лабораторная работа №1 (Цветовые модели)
* lab2/ — Лабораторная работа №2 (Геометрические преобразования)
* lab3/ — Лабораторная работа №3 (Алгоритмы растеризации)

### Как быстро запустить программы (Windows)

Для проверки в папки лабораторных работ добавлены готовые .zip архивы.
1. Скачайте архив нужной лабораторной работы (например, colorModels_exe.zip из папки lab1).
2. Распакуйте архив в любую удобную папку на компьютере.
3. Откройте распакованную папку и запустите исполняемый файл **ColorModels.exe** (или соответствующий .exe файл).
